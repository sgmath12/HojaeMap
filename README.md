# 호재맵 (HojaeMap)

전국 부동산 호재를 지역별로 시각화하는 인터랙티브 지도. 단일 HTML 파일로 동작하며 빌드 과정이 없습니다.

지도를 확대하면 **시도 → 시군구 → 행정동** 3단계로 자동 세분화되고, 지역을 클릭하면 우측 사이드바에 호재지수·9개 지표·관련 뉴스가 표시됩니다.

## 실행 방법

⚠️ **HTML 파일을 더블클릭하면 지도가 뜨지 않습니다.** `fetch()`로 경계 데이터를 읽는데 `file://` 환경에서는 브라우저 보안 정책상 차단되기 때문입니다.

반드시 로컬 서버로 띄워주세요:

```bash
python3 -m http.server 8123
```

그리고 브라우저에서 http://localhost:8123/realestate-map_new.html 접속.

## 파일 구조

| 파일 | 설명 |
|---|---|
| `realestate-map_new.html` | **본체.** 지도 렌더링, 3단계 줌, 필터, 사이드바 |
| `data-regions.js` | 지역 데이터 (시도 17 · 시군구 52 · 행정동 173) |
| `geo-sido.json` | 시도 경계 TopoJSON — 17개 |
| `geo-sigungu.json` | 시군구 경계 TopoJSON — 250개 |
| `geo-dong.json` | 행정동 경계 TopoJSON — 3,504개 (지연 로딩) |
| `realestate-map.html` | 구버전 (2단계 줌, 4개 지표). 동작하지 않음 — 참고용 |
| `skorea-*-geo.json` | 구버전이 쓰던 GADM 경계 데이터. 현재 미사용 |

경계 데이터는 [southkorea/southkorea-maps](https://github.com/southkorea/southkorea-maps)의 통계청 2018년 기준 TopoJSON입니다. 같은 데이터의 GeoJSON 형식은 합계 60MB인데 TopoJSON은 6.9MB로, 약 9배 작습니다.

## 기술 스택

- [Leaflet 1.9.4](https://leafletjs.com/) — 지도 렌더링 (CDN)
- [topojson-client 3](https://github.com/topojson/topojson-client) — TopoJSON → GeoJSON 변환 (CDN)
- CARTO Light 타일 — 베이스맵
- Noto Sans KR — 폰트 (Google Fonts)
- 프레임워크·번들러 없음

## 3단계 줌

| 줌 레벨 | 표시 단위 | 개수 |
|---|---|---|
| ~8 | 시도 | 17 |
| 9~11 | 시군구 | 250 |
| 12~ | 행정동 | 3,504 |

행정동 경계 파일은 4MB라서 **처음 그 줌에 도달할 때 한 번만** 내려받습니다. 초기 로딩에는 포함되지 않습니다.

## 데이터 구조

지역 데이터는 `data-regions.js`에 **통계청 행정구역 코드**를 키로 정의되어 있습니다. 코드가 계층 구조라 상위/하위 관계를 문자열 자르기만으로 알 수 있습니다.

```
시도     2자리   "31"        경기도
시군구   5자리   "31023"     성남시분당구
행정동   7자리   "3102378"   정자동
```

```js
// R(이름, 종합점수, [지표 9개], [테마태그], [[유형, 내용, 날짜], ...])
"3102378": R("정자동", 90, [95,82,80,76,90,92,92,84,88],
  ["🚇 신분당선+수인분당선 더블역세권", "☕ 정자동 카페거리", "🏫 분당 학원가"],
  [["transport", "정자역 신분당선·수인분당선 환승 — 강남 20분대", "2025.01"]]),
```

지표 배열 순서는 `[교통, 개발, 정책, 공급, 직주근접, 학군, 라이프, 인구, 미래가치]` 입니다.

### 상속

데이터가 없는 지역은 **상위 단계 값을 상속**합니다. 예를 들어 `3102365`(미작성 동)를 조회하면 상위인 `31023` 성남시분당구 값이 쓰이고, 사이드바와 툴팁에 "분당구 기준 참고값"이라고 표시됩니다.

### 9개 지표

| 키 | 지표 | 의미 |
|---|---|---|
| `transport` | 🚇 교통 | GTX·지하철·버스 등 교통 인프라 및 역세권 접근성 |
| `develop` | 🏗 개발 | 재개발·재건축·신도시 개발 사업 |
| `policy` | 📋 정책 | 규제완화·정비사업 정책 수혜 |
| `supply` | 🏠 공급 | 입주물량·전세가 수급 상황 |
| `job` | 💼 직주근접 | 대형 고용지 접근성 |
| `school` | 🏫 학군파워 | 학원가·명문교 밀집도 |
| `life` | 🌱 라이프 | 한강·공원·카페 등 생활 인프라 |
| `population` | 👥 인구모멘텀 | MZ세대 유입·인구 순증 |
| `future` | 🔮 미래가치 | AI·반도체·바이오 산업 수혜 |

상단 필터 칩으로 특정 지표를 선택하면 지도 색상과 뉴스 목록이 해당 지표 기준으로 다시 계산됩니다.

동 단위 데이터는 같은 구 안에서도 역세권·학원가·개발축에 따라 편차가 큰 지역 위주로 작성되어 있습니다. 예를 들어 분당구에서 정자동(90점, 더블역세권)과 분당동(82점, 역세권 이격)이 구분되고, 강남구에서 대치1동은 학군 100점, 삼성1동은 미래가치 98점으로 갈립니다.

## ⚠️ 데이터에 대한 경고

**점수는 실제 시세·공시가·실거래가와 연동된 값이 아닙니다.** 공개된 개발계획, 역세권 분포, 학원가 위치 등을 근거로 산정한 추정치이며, **투자 판단 근거로 쓸 수 없습니다.**

실제 데이터로 대체하려면 국토교통부 실거래가 공개 API(법정동 단위 아파트 매매가)와 지하철역 좌표 기반 역세권 거리 계산을 붙이는 방향이 적절합니다.

## 알려진 한계

- 시군구 250곳 중 52곳, 행정동 3,504곳 중 173곳에만 개별 데이터가 있습니다. 나머지는 상위 단계 값을 상속합니다.
- `AI 심층 분석` 버튼은 아직 동작하지 않는 자리표시자입니다.
- 지도 색상이 빨강~파랑 대립 팔레트라 점수가 낮은 지역이 부정적으로 읽힐 수 있습니다. 시인성을 우선해 현행 유지 중입니다.
