# 호재맵 (HojaeMap)

전국 부동산 호재를 지역별로 시각화하는 인터랙티브 지도. 단일 HTML 파일로 동작하며 빌드 과정이 없습니다.

지도를 확대하면 **시도 단위 → 시군구 단위**로 자동 전환되고, 지역을 클릭하면 우측 사이드바에 호재지수·세부 지표·관련 뉴스가 표시됩니다.

## 실행 방법

⚠️ **HTML 파일을 더블클릭하면 지도가 뜨지 않습니다.** `fetch()`로 GeoJSON을 읽는데 `file://` 환경에서는 브라우저 보안 정책상 차단되기 때문입니다.

반드시 로컬 서버로 띄워주세요:

```bash
python3 -m http.server 8123
```

그리고 브라우저에서 http://localhost:8123/realestate-map_new.html 접속.

## 파일 구조

| 파일 | 설명 |
|---|---|
| `realestate-map_new.html` | **현행 버전.** 9개 지표, 유형 필터, 테마 태그 지원 |
| `realestate-map.html` | 구버전. 4개 지표만 지원 (참고용) |
| `skorea-provinces-geo.json` | 시도 경계 GeoJSON |
| `skorea-municipalities-geo.json` | 시군구 경계 GeoJSON |

## 기술 스택

- [Leaflet 1.9.4](https://leafletjs.com/) — 지도 렌더링 (CDN)
- CARTO Light 타일 — 베이스맵
- Noto Sans KR — 폰트 (Google Fonts)
- 프레임워크·번들러 없음. 데이터는 HTML 안에 인라인 상수로 하드코딩

## 데이터 구조

지역 데이터는 HTML 내 `SIDO` / `SIGUNGU` 객체에 직접 정의되어 있습니다.

```js
"Seoul|Gangnam": {
  name: "강남구",
  score: 95,                        // 종합 호재지수 (0~100)
  transport: 88, develop: 92,       // 기본 지표
  policy: 95, supply: 85,
  job: 98, school: 99, life: 92,    // 정성 지표
  population: 88, future: 96,
  tags: ["🏆 전국 최고 학군", ...],   // 사이드바 테마 배지
  news: [                           // 호재/악재 타임라인
    { t: "policy", tx: "압구정·대치 재건축 안전진단 완화 수혜", d: "2025.03" }
  ]
}
```

### 9개 지표

| 키 | 지표 | 의미 |
|---|---|---|
| `transport` | 🚇 교통 | GTX·지하철·버스 등 교통 인프라 |
| `develop` | 🏗 개발 | 재개발·재건축·신도시 개발 사업 |
| `policy` | 📋 정책 | 규제완화·정비사업 정책 수혜 |
| `supply` | 🏠 공급 | 입주물량·전세가 수급 상황 |
| `job` | 💼 직주근접 | 대형 고용지 접근성 |
| `school` | 🏫 학군파워 | 학원가·명문교 밀집도 |
| `life` | 🌱 라이프 | 한강·공원·카페 등 생활 인프라 |
| `population` | 👥 인구모멘텀 | MZ세대 유입·인구 순증 |
| `future` | 🔮 미래가치 | AI·반도체·바이오 산업 수혜 |

상단 필터 칩으로 특정 지표를 선택하면 지도 색상과 뉴스 목록이 해당 지표 기준으로 다시 계산됩니다.

## 지도 색상

호재 강도를 **파랑 단일 색상의 농도**로 표현합니다. 연할수록 호재 정보가 적고, 진할수록 호재가 집중된 지역입니다. 데이터가 아직 없는 지역은 회색으로 둡니다.

색상은 지역의 우열이나 등급이 아니라 **수집된 호재 정보량**을 나타냅니다.

## 알려진 한계

- **데이터는 예시값입니다.** 실제 시세·공시가·정책 자료와 연동되어 있지 않으며 투자 판단 근거로 쓸 수 없습니다.
- 시군구 데이터 커버리지가 아직 낮습니다. 데이터가 없는 지역은 회색으로 표시됩니다.
- `AI 심층 분석` 버튼은 아직 동작하지 않는 자리표시자입니다.
