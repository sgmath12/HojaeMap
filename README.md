# 호재맵 (HojaeMap)

전국 부동산 호재를 지역별로 시각화하는 인터랙티브 지도. 단일 HTML 파일로 동작하며 빌드 과정이 없습니다.

지도를 확대하면 **시도 → 시군구 → 행정동** 3단계로 자동 세분화됩니다.

동네를 누르면 점수가 아니라 **이야기**가 나옵니다. 부동산 초년생이 대상이라
"82점"은 아무 의미가 없기 때문입니다.

```
정자동                                    [87]
성남시분당구

🚇  역까지 걸어서 5분이면 가요
    👉 이게 여기서 제일 커요

💼  대형 일자리가 코앞이에요
    판교 테크노밸리 인접 + 정자 오피스 권역

🌱  상권이랑 공원이 아주 잘 갖춰져 있어요
    정자동 카페거리·탄천 수변 라이프

  ▸ 숫자로 보기
```

점수는 오른쪽 위 배지로만 남고, 9개 지표·실측값·원본 뉴스는 접혀 있습니다.

## 실행 방법

⚠️ **HTML 파일을 더블클릭하면 지도가 뜨지 않습니다.** `fetch()`로 경계 데이터를 읽는데 `file://` 환경에서는 브라우저 보안 정책상 차단되기 때문입니다.

반드시 로컬 서버로 띄워주세요:

```bash
python3 -m http.server 8123
```

그리고 브라우저에서 http://localhost:8123/realestate-map_new.html 접속.

| `tools/build-metrics.py` | 실측 지표 생성기 (OpenStreetMap) |

경계 데이터는 [southkorea/southkorea-maps](https://github.com/southkorea/southkorea-maps)의 통계청 2018년 기준 TopoJSON입니다. 같은 데이터의 GeoJSON 형식은 합계 60MB인데 TopoJSON은 6.9MB로, 약 9배 작습니다.

## 기술 스택

- [Leaflet 1.9.4](https://leafletjs.com/) — 지도 렌더링 (CDN)
- [topojson-client 3](https://github.com/topojson/topojson-client) — TopoJSON → GeoJSON 변환 (CDN)
- CARTO Light 타일 — 베이스맵
- Noto Sans KR — 폰트 (Google Fonts)
- 프레임워크·번들러 없음

## 3단계 줌

| 줌 레벨 | 표시 단위 | 개수 |
|---|---|---|
| ~8 | 시도 | 17 |
| 9~11 | 시군구 | 250 |
| 12~ | 행정동 | 3,504 |

행정동 경계 파일은 4MB라서 **처음 그 줌에 도달할 때 한 번만** 내려받습니다. 초기 로딩에는 포함되지 않습니다.

## 데이터 구조

지역 데이터는 `data-regions.js`에 **통계청 행정구역 코드**를 키로 정의되어 있습니다. 코드가 계층 구조라 상위/하위 관계를 문자열 자르기만으로 알 수 있습니다.

```
시도     2자리   "31"        경기도
시군구   5자리   "31023"     성남시분당구
행정동   7자리   "3102378"   정자동
```

```js
// R(이름, 종합점수, [지표 9개], [테마태그], [[유형, 내용, 날짜], ...])
"3102378": R("정자동", 87, [95,76,74,78,92,88,92,84,86],
  ["🚇 신분당선+수인분당선 더블역세권", "☕ 정자동 카페거리"],
  [["transport", "정자역 신분당선·수인분당선 환승 — 강남 20분대", "2025.01"]]),
```

지표 배열 순서는 `[교통, 개발, 정책, 공급, 직주근접, 학군, 라이프, 인구, 미래가치]` 입니다.

### 상속

데이터가 없는 지역은 **상위 단계 값을 상속**합니다. 미작성 동을 조회하면 상위인
성남시분당구 값이 쓰이고, 사이드바와 툴팁에 "분당구 기준 참고값"이라고 표시됩니다.

단 **시도에서 물려받을 때는 시도 점수가 아니라 `SIDO_BASE`의 외곽 기준값**을 씁니다.
시도 점수는 상위 지역이 끌어올린 값이라 그대로 물려주면 부풀려지기 때문입니다.
경기 70은 판교·용인·과천이 만든 값이라 이천시에 쓰면 서울 양천구와 동점이 됩니다.

### 9개 지표

| 키 | 지표 | 의미 |
|---|---|---|
| `transport` | 🚇 교통 | GTX·지하철·버스 등 교통 인프라 및 역세권 접근성 |
| `develop` | 🏗 개발 | 재개발·재건축·신도시 개발 사업 |
| `policy` | 📋 정책 | 규제완화·정비사업 정책 수혜 |
| `supply` | 🏠 공급 | 입주물량·전세가 수급 상황 |
| `job` | 💼 직주근접 | 대형 고용지 접근성 |
| `school` | 🏫 학군파워 | 학원가·명문교 밀집도 |
| `life` | 🌱 라이프 | 한강·공원·카페 등 생활 인프라 |
| `population` | 👥 인구모멘텀 | MZ세대 유입·인구 순증 |
| `future` | 🔮 미래가치 | AI·반도체·바이오 산업 수혜 |

상단 필터 칩으로 특정 지표를 선택하면 지도 색상과 뉴스 목록이 해당 지표 기준으로 다시 계산됩니다.

동 단위 데이터는 같은 구 안에서도 역세권·학원가·개발축에 따라 편차가 큰 지역 위주로
작성되어 있습니다. 분당구에서는 1기 신도시 선도지구인 서현1동(91점)·수내1동(90점)이
위고, 정자동(87점)은 교통 95점으로 앞서지만 주상복합 비중이 높아 재건축 수혜에서
비껴 있습니다. 강남구에서는 대치1동이 학군 100점, 삼성1동이 미래가치 98점으로 갈립니다.

## 검색

동네 이름으로 찾습니다. 시도·시군구·행정동 3,672곳이 색인되어 있고, ↑↓ 키와
엔터로도 고를 수 있습니다.

같은 이름이 여러 곳일 때는 점수가 높은 쪽을 위로 올립니다 — "대치"를 치면
강남 대치1동이 진안 대치면보다 먼저 나옵니다.

행정동 경계는 지연 로딩이라, 동을 검색하면 경계 파일을 받은 뒤 이동합니다.

## 점수는 어떻게 나오나

종합점수는 9개 지표의 **가중평균**에 시세를 28% 섞은 값입니다.

| 지표 | 비중 | | 지표 | 비중 |
|---|---|---|---|---|
| 🚇 교통 | 14% | | 📋 정책 | 11% |
| 🏗 개발 | 14% | | 🏫 학군 | 11% |
| 💼 직주근접 | 14% | | 🌱 라이프 | 9% |
| 🔮 미래가치 | 13% | | 🏠 공급 · 👥 인구 | 각 7% |

카드에 **점수 분해 막대**가 있어서 어느 지표가 얼마나 기여했는지 바로 보입니다.
막대 길이를 다 더하면 종합점수가 됩니다.

```
강남구
  💼 직주근접  98 × 14% = 13.7
  🏗 개발     92 × 14% = 12.9
  🔮 미래가치  96 × 13% = 12.5
  ...                    ─────
                          93점  + 시세 98 × 28% → 94
```

## 모바일

720px 이하에서는 사이드바가 **바텀시트**로 바뀝니다. 손잡이를 끌거나 눌러
펼치고 접으며, 지도는 화면 전체를 채우고 있어 시트를 내리면 그만큼 지도가
넓어집니다.

## 관심 지역

⭐로 담아두면 목록에서 눌러 바로 이동합니다. 브라우저 `localStorage`에만
저장되고 서버로 가지 않습니다.

## 계산 지표 (실측)

일부 값은 사람 판단이 아니라 좌표 계산에서 나옵니다. `tools/build-metrics.py`가
OpenStreetMap 데이터로 **행정동 3,504개 전부**에 대해 만들며 결과는
`data-metrics.js`에 들어갑니다.

```bash
python3 tools/build-metrics.py            # 캐시 재사용 (약 6초)
python3 tools/build-metrics.py --refresh  # Overpass에서 원본 다시 받기
```

| 값 | 계산 방식 | 품질 |
|---|---|---|
| `transport` | 최단 역까지 거리 + 반경 1km 역 개수 | **좋음 — 교통 점수를 대체함** |
| `redev` | 정비사업 공급세대수 × 단계 가중치 | **좋음 — 카드에 실측으로 표시** |
| `price` | 아파트 실거래 평당가 중앙값 | **좋음 — 카드에 실측으로 표시** |
| `school_access` | 반경 내 초·중·고 밀도의 전국 백분위 | 참고용 (학군 아님) |
| `life_density` | 반경 내 공원·카페 밀도의 전국 백분위 | 참고용 (라이프 아님) |

### 활동 중심점

행정동은 산·논밭까지 포함해 넓기 때문에 폴리곤의 기하학적 중심을 쓰면 사람 사는
곳과 어긋납니다. 구미1동이 그랬습니다 — 대표점 기준 오리역까지 2,296m가 나오는데
실제 주거지는 역 바로 옆입니다.

그래서 동 내부를 격자로 훑고 각 점을 반경 400m 안의 카페·학교 수로 가중해
**활동 중심점**을 구합니다. 같은 방식으로 구미1동은 313m가 됩니다. POI가 전혀
없는 산간·농촌 109개 동은 대표점으로 되돌립니다.

### school_access·life_density를 왜 안 쓰나

검증해보니 이름이 뜻하는 것과 재는 것이 다릅니다.

- `school_access` 상위권이 중림동·청파동·돈암1동처럼 오래된 고밀 주거지이고
  대치1동은 3,504곳 중 172위에 그칩니다. **학원가가 아니라 학교 밀도**, 사실상
  인구 밀도를 재고 있습니다.
- `life_density` 상위권은 소공동·명동·회현동 같은 도심 상업지구입니다. 거주
  쾌적성이 아니라 **상업 POI 밀도**입니다.

둘 다 진짜 측정값이긴 하지만 학군·라이프 점수로 쓰면 틀린 결론이 나옵니다.
그래서 사이드바에 참고 정보로만 노출하고 점수를 덮어쓰지 않습니다.

## 정비사업 (실측)

`data/`의 공공데이터 CSV를 `tools/build-redev.py`가 집계해 `data-redev.js`를 만듭니다.
전국 1,566건, 시군구 142곳 · 행정동 171곳을 커버합니다.

```bash
python3 tools/build-redev.py
```

| 출처 | 건수 | 쓰임 |
|---|---|---|
| 국토교통부 전국 도시정비사업 통합 데이터 | 1,566 | 시군구 기준 (100% 매칭) |
| 서울시 정비사업 데이터 | 106 | 동 단위 (법정동명 → 행정동) |
| 경기도 일반정비사업추진현황 | 111 | 동 단위 (주소 → 행정동) |
| 인천광역시 정비사업 추진현황 | 2 | 동 단위 |

### 두 가지를 조심했습니다

**준공·청산은 뺍니다.** 이미 끝난 사업이라 앞으로의 호재가 아닙니다 (71건 제외).

**규모는 구역 수가 아니라 공급 세대수로 잽니다.** 구역 수로 세면 결과가 뒤집힙니다:

| | 구역 수 | 공급 세대수 | 성격 |
|---|---|---|---|
| 종로구 | 70개 | 3,678세대 | 전부 상업지 도시환경정비 |
| 강남구 | 26개 | 37,514세대 | 전부 아파트 재건축 |

구역 수 기준으로는 종로구가 1위, 강남구가 14위였습니다. 주거 호재를 보는
지도에서는 틀린 답이라 세대수 가중으로 바꿨습니다. 그 결과 양천구(목동 재건축
61,983세대)와 광명시(광명뉴타운 53,157세대)가 1·2위가 됩니다.

단계별 가중치는 "얼마나 확실하고 임박했는가"입니다 — 착공 1.0, 관리처분 0.9,
사업시행인가 0.75, 조합설립 0.55, 정비구역 지정 0.35, 추진위 0.25.

### 한계

법정동과 행정동은 1:1이 아니라, 이름이 어긋나는 곳(서소문동→소공동, 용두동→
용신동)은 **잇지 않고 비워둡니다.** 틀린 동네에 표시하느니 표시하지 않는 편이
낫기 때문입니다. 그런 동은 상위 시군구 값을 쓰고 "구 전체 기준"이라고 밝힙니다.

## 실거래가 (실측)

국토교통부 아파트 매매 실거래가 오픈API에서 받아 `data-prices.js`를 만듭니다.
**최근 3개월 118,881건**, 시군구 214곳 · 법정동 2,264곳. 행정동 기준으로는
3,504곳 중 3,011곳(86%)에 가격이 붙습니다.

```bash
python3 tools/fetch-prices.py --verify         # 코드표 검증만
python3 tools/fetch-prices.py --months 3       # 전국 (약 10분)
python3 tools/fetch-prices.py --months 3 --sido 11 31
```

인증키는 `data/api_key.md`에서 읽습니다. **이 파일은 `.gitignore`에 있어
저장소에 올라가지 않습니다.** 환경변수 `MOLIT_API_KEY`로 덮어쓸 수 있습니다.

### 세 가지를 조심했습니다

**해제된 거래는 뺍니다** (3,860건). 계약이 취소된 건이라 시세가 아닙니다.

**평균이 아니라 중앙값을 씁니다.** 초고가 한 건이 동네 대표값을 흔들지 않게요.

**코드 체계가 다릅니다.** API는 법정동 코드, 지도는 통계청 코드를 씁니다
(종로구: 법정동 11110 ↔ 통계청 11010). `tools/lawd.py`의 표로 잇고,
`--verify`로 응답의 `sggCd`와 대조해 확인합니다 — 218곳 일치, 불일치 0.

> 검증에 `estateAgentSggNm`(중개사 소재지)을 쓰면 안 됩니다. 중개사 위치는
> 매물 위치와 달라서(부산 중구 매물을 동구 중개사가 거래) 멀쩡한 코드가 틀린
> 것처럼 나옵니다. 실제로 그렇게 오판했습니다.

### 법정동 ↔ 행정동

이름이 어긋나는 것을 맞춰 잇습니다.

| 지도(행정동) | 실거래(법정동) | 처리 |
|---|---|---|
| 신정4동 | 신정동 | 숫자 떼기 |
| 문래동 | 문래동1~6가 | 여럿을 묶어 중앙값 |
| 여의동 | 여의도동 | 별칭표 |

못 이으면 시군구 값으로 떨어지고, 카드에 "구 전체 기준"이라고 밝힙니다.

### 검증

평당가 상위가 실제 시장과 맞는지 확인했습니다.


## ⚠️ 데이터에 대한 경고

사이드바에 **실측** 배지가 붙은 값(교통)과 "실측 정보" 절의 숫자만 좌표 계산에서
나온 것입니다. **나머지 점수는 전부 추정치입니다** — 공개된 개발계획과 지역 특성을
근거로 산정했지만 실제 시세·공시가와 연동되어 있지 않고, **투자 판단 근거로 쓸 수
없습니다.**

추정치는 틀릴 수 있습니다. 실제로 초기 버전은 분당구에서 정자동을 1위로 뒀는데,
1기 신도시 선도지구(서현 시범단지·수내 양지마을·이매 샛별마을) 지정을 정책 지표에
전혀 반영하지 않은 오류였습니다.
